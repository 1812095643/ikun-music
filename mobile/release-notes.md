ikun音乐 Android 0.1.2

- 启动后自动检查安卓新版本，发现更新时显示提示；也可在“设置 → 检查更新”手动检查。
- 支持下载进度、取消与重试；下载完成后校验文件完整性、应用身份和签名，再唤起系统安装确认。
- 已完整下载的安装包可重新校验后继续安装；应用在后台时不会突然弹出安装页面。
- 只检查安卓发行版，不会误提示 Windows 或 Mac 版本。

  0.1.1 及更早版本还没有更新检测功能，需要先手动覆盖安装本版，保留原有数据。首次应用内更新时，Android 可能要求允许“安装未知应用”，授权返回后继续安装。

适用于 Android 8.0 及以上，手机、平板和车机共用 ARM64 / ARM32 安装包。iOS 当前尚无签名安装包。
