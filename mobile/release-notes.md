# ikun音乐 Android 0.1.8

- 补齐单曲播放、单曲循环、列表播放、列表循环、随机播放五种模式，设置页、播放页和播放队列统一显示名称与图标。
- 单曲播放结束即停，列表播放到末尾停止，列表循环回到第一首；单曲循环时仍可手动切换歌曲。
- 随机播放改为打乱队列，一轮内不重复，上一首可返回刚听过的歌曲；退出随机模式恢复原顺序。
- 修复重复结束通知、连续切歌和解析音源时切换模式造成的目标错位；歌曲结束后再点播放从头开始。
- 系统播放卡片的切歌可用状态跟随当前模式更新，手机、平板和车机共用相同规则。

本版通过 54 项播放回归检查、桌面与移动端类型检查及浏览器真实音频验证；本次未进行小米、vivo、OPPO 真机复测。

适用于 Android 8.0 及以上，手机、平板和车机共用 ARM64 / ARM32 APK，沿用原签名，可覆盖安装并保留数据。0.1.2 及以上版本可在“设置 → 检查更新”下载，系统仍需确认安装。

Windows 与 macOS 安装包见 [桌面 5.3.14 发布页](https://github.com/1812095643/ikun-music/releases/tag/v5.3.14)。iOS 当前尚无签名安装包。
